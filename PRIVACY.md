# Política de Privacidade — Missão em Cortes Publisher

Última atualização: outubro de 2026

O **Missão em Cortes Publisher** é uma ferramenta interna, de uso exclusivo do responsável
pelo canal "Missão em Cortes" no YouTube. Ela não é oferecida, vendida ou distribuída como
serviço a terceiros.

## Uso dos Serviços de API do YouTube
Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, você concorda com os
Termos de Serviço do YouTube: https://www.youtube.com/t/terms
O tratamento de dados pelo Google segue a Política de Privacidade do Google:
https://policies.google.com/privacy

## Quais dados são acessados
A ferramenta acessa apenas a conta do YouTube do próprio responsável pelo canal, mediante
autorização OAuth, para enviar vídeos, agendar publicações e definir títulos, descrições,
tags e miniaturas. Ela não acessa dados de outros usuários ou de outros canais.

## Quais dados são armazenados
São armazenados localmente, no computador do responsável, somente:
- o token de autorização OAuth, para manter o acesso à própria conta;
- o ID e a data de agendamento dos vídeos publicados pela própria ferramenta.

Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

## Retenção e exclusão
Os dados ficam armazenados enquanto o vídeo existir no canal. O token e os registros locais
podem ser apagados a qualquer momento, removendo os arquivos da ferramenta.

## Como revogar o acesso
O acesso da ferramenta à conta Google pode ser revogado a qualquer momento em:
https://security.google.com/settings/security/permissions
