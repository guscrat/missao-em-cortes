Missão em Cortes Publisher

O Missão em Cortes Publisher é uma ferramenta interna de publicação do canal Missão em Cortes no YouTube, usada exclusivamente pelo responsável pelo canal.

Ela usa os Serviços de API do YouTube para enviar os vídeos do próprio canal e definir título, descrição, tags e miniatura de cada um. Não é oferecida a terceiros e não acessa dados de outros usuários ou canais.
