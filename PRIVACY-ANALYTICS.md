# Política de Privacidade — Missão em Cortes Analytics

Última atualização: outubro de 2026

O **Missão em Cortes Analytics** é uma ferramenta interna, só de leitura, de uso exclusivo do
responsável pelo canal "Missão em Cortes" no YouTube. Ela é um cliente separado, num projeto
do Google próprio, distinto da ferramenta de publicação. Não é oferecida, vendida ou
distribuída como serviço a terceiros.

## Uso dos Serviços de API do YouTube
Esta ferramenta usa os Serviços de API do YouTube (YouTube Analytics API e YouTube Data API).
Ao usá-la, você concorda com os Termos de Serviço do YouTube: https://www.youtube.com/t/terms

O tratamento de dados pelo Google segue a Política de Privacidade do Google:
https://policies.google.com/privacy

## Quais dados são acessados
Mediante autorização OAuth, com acesso somente leitura (escopos `yt-analytics.readonly` e
`youtube.readonly`), a ferramenta lê apenas dados do próprio canal Missão em Cortes:
- a lista de vídeos públicos do canal (título, data de publicação e duração);
- métricas agregadas de cada vídeo: visualizações, duração média assistida e porcentagem
  média assistida.

A ferramenta não envia, altera nem apaga nada no canal. Ela não acessa dados de outros canais
nem dados pessoais de espectadores.

## Quais dados são armazenados
São armazenados localmente, no computador do responsável, somente:
- o token de autorização OAuth, para manter o acesso de leitura à própria conta;
- os números de retenção calculados a partir dessas métricas, guardados no banco local do
  painel interno do canal.

Nenhum dado é vendido, compartilhado com terceiros ou usado para publicidade.

## Retenção e exclusão
Os números ficam guardados enquanto forem úteis para acompanhar o desempenho do canal. O token
e os registros locais podem ser apagados a qualquer momento, removendo os arquivos da
ferramenta.

## Como revogar o acesso
O acesso da ferramenta à conta Google pode ser revogado a qualquer momento em:
https://security.google.com/settings/security/permissions
